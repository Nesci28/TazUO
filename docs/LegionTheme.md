# Legion UI theme

The Legion theme uses the same dark teal, bronze, and gold palette as
`LegionScripts/_Utils/Gump.py`. It is enabled by default for paperdolls.

## Paperdolls

The **Paperdoll** options page includes **Use dark teal and gold paperdolls**. The option applies
to both the classic paperdoll and TazUO's modern paperdoll. Classic paperdolls retain their native
buttons, equipment interaction, scaling, minimizer, and saved position. The modern paperdoll uses
a fixed 250×380 themed background aligned to its existing equipment slots.
